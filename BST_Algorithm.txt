ALGORITHM: BINARY SEARCH TREE USING LINKED LIST

Operations: Insert a new node, delete a node, and count leaf nodes.


1. INSERT A NODE
1. Start.
2. If the root is NULL, create a new node with the given value and make it the root.
3. Otherwise, compare the value with the current node.
4. If the value is smaller, move to the left subtree; if larger, move to the right subtree.
5. Repeat the comparison until a NULL position is reached.
6. Create the new node at that position. If the value already exists, reject the duplicate.
7. Return the root and stop.


2. DELETE A NODE
1. Start.
2. Search for the node containing the given value.
3. If the node is not found, display "Node not found" and stop.
4. If the node has no children, delete it and set its link to NULL.
5. If the node has only one child, replace the node with its child and free the deleted node.
6. If the node has two children, find the smallest node in its right subtree (inorder successor).
7. Copy the successor's value into the node, then delete the successor from the right subtree.
8. Return the updated root and stop.


3. COUNT LEAF NODES
1. Start.
2. If the current node is NULL, return 0.
3. If both left and right pointers are NULL, return 1.
4. Otherwise, recursively count the leaf nodes in the left and right subtrees.
5. Return the sum of both counts and stop.


4. MAIN ALGORITHM
1. Start and initialize root = NULL.
2. Display the menu: Insert, Delete, Count Leaf Nodes, Display BST, and Exit.
3. Read the user's choice.
4. If Insert is selected, read a value and call the insertion algorithm.
5. If Delete is selected, read a value and call the deletion algorithm.
6. If Count Leaf Nodes is selected, call the leaf-counting algorithm and display the result.
7. If Display is selected, perform inorder traversal (Left, Root, Right).
8. If Exit is selected, terminate the program; otherwise, display "Invalid choice" for an invalid option.
9. Repeat the menu until Exit is selected.
10. Stop.
